# 📊 Student Performance Data Analysis

## 📌 Project Overview
This project analyzes student academic performance using Python. It uses Pandas, NumPy, and Matplotlib to calculate marks, assign grades, identify missing values, and visualize student performance.

## 🎯 Objectives
- Analyze student academic performance.
- Calculate total and average marks.
- Assign grades based on average marks.
- Identify missing values and duplicate records.
- Visualize student marks and attendance.
- Generate meaningful performance insights.

## 🛠️ Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib

## 📂 Project Files
- `Student_Performance_Analysis.ipynb` – Python analysis notebook.
- `student_performance.csv` – Student academic dataset.

## 📈 Analysis and Visualizations
- Subject-wise performance comparison.
- Grade distribution.
- Average marks analysis.
- Student attendance analysis.

## 💡 Key Insights
The project identifies top-performing students, calculates subject-wise averages, examines grade distribution, and analyzes student attendance.

## 🚀 How to Run
1. Download the notebook and CSV dataset.
2. Open Google Colab.
3. Upload the notebook.
4. Upload the CSV dataset to the Colab session.
5. Run the notebook cells in order.
